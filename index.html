1. Introduction to React

React is a JavaScript library used to build user interfaces (UIs). It helps you create fast, easily manageable single-page applications (SPAs) that update dynamically without reloading the entire browser window.

Key Features

  • Component-based ecosystem
  • High reusability of building blocks
  • Fast performance via the Virtual DOM

Virtual DOM Mechanics

React maintains an in-memory duplicate copy of the real DOM structure. When state shifts, it computes changes dynamically against this copy and alters only the uniquely affected nodes to maximize rendering velocities.

3. JSX Basics

JavaScript XML (JSX) allows writing cleanly semantic markup explicitly inside native JavaScript architectures.

Syntax Rules: Must consistently return a singular consolidated parent element. Attributes employ strict camelCase mapping configurations (e.g., className or onClick). 
// Embedding Expressions Expression Scope Demo

const element = <h1>Hello, {name}!</h1>;

5. State Management

Leveraging reactive local tracking states explicitly using structural hooks.

import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);
  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>Add</button>
    </div>
  );
}

10. useEffect Hook

Isolating structural side-effects cleanly across specific engine lifecycles.

import { useEffect } from 'react';

useEffect(() => {
  console.log("Component dynamically mounted into DOM layer");
}, []); // Empty dependency configurations compute exactly once

20. Portals in React

Rendering interactive markup targets completely outside isolated traditional mounting hierarchies.

import ReactDOM from "react-dom";

function Modal({ onClose, children }) {
  return ReactDOM.createPortal(
    <div class="modal-overlay">
      <div class="modal-content">{children}</div>
    </div>,
    document.getElementById("portal-root")
  );
}

Mistake Why It's a Problem Correct Approach

Missing keys in lists React breaks standard performance tracing across dynamic list layers. Pass isolated distinct tracking indices via key properties.
